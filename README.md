# Vinheria Agnello - Check-Point 03

Página web da Vinheria Agnello, uma loja de vinhos fictícia, feita para praticar layouts com Flexbox, pseudo-classes e transformações CSS.

## O que foi usado

- Flexbox: cabeçalho, menu, destaque, cards, seção Sobre, newsletter e rodapé
- Pseudo-classes: `:hover`, `:focus`, `:active` e `:nth-child`
- Transformações: `scale()`, `translateY()`, `translateX()` e `rotate()`, com `transition`
- Layout responsivo para celular
